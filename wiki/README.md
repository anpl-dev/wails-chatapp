## 運用ルール（簡易）

- 仕様変更時は先にこの`wiki/`を更新する
- 実装の判断基準は`wiki/`を正とする
- 大きな方針変更はPR単位で履歴を残す
- ファイル名は `b番号_*.md` / `f番号_*.md` 形式で管理する
  - `b`: backend
  - `f`: frontend
